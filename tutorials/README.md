# Tutorials

Hands-on tutorials for Prime Intellect Lab. Do them in order — each builds on the previous one.

## Basics

From nothing to your first eval, RL run, and GEPA run:

- [Hello, Prime Intellect Lab](0_hello.md) — what Lab is, and the mental model everything builds on.
- [Setup](1_setup.md) — install the CLI, authenticate, run a smoke-test eval.
- [Your First Eval](2_first_eval.md) — measure a model on grade-school math, then multi-turn Wordle.
- [Your First RL Run](3_first_rl.md) — train a small model on hosted GPUs and watch it improve.
- [Your First GEPA Run](4_first_gepa.md) — evolve a better prompt automatically, without touching weights.

## Ramping up

The building blocks of environment authoring, one at a time:

- [Build Your First Environment](5_build_first_environment.md) — tasks, configs, and tasksets, built on AIME 2026.
- [Judges](6_judges.md) — score the tone of a response with an LLM judge.
- [Designing Rewards](7_rewards.md) — weighted rewards, metrics, stop conditions, and group rewards.
- [User Simulators](8_user_simulators.md) — the environment plays the human side of the conversation.
- [Multimodal Environments](9_multimodal.md) — tasks that carry images, not just text.
- [Tool Use and Search](10_tools.md) — toolsets, placement, and reading tool traces.
- [Coding Agent Environments](11_coding_agents.md) — runtimes, interpreters, Docker, and Harbor tasksets.
- [Best Practices](12_best_practices.md) — the authoring checklist and common failure modes.
